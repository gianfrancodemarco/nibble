nibble PRD Roadmap Mockups Docs GitHub

Design mockups v0.2. Picture first, prose last: the agent's explanation becomes an interactive model of your code, served in small nibbles. Section 02 is live, so try it.

Opinions

01Picture first, prose last

Every nibble leads with a visual. The caption is one or two sentences, never a paragraph.

02Interactive, not animated

Every visual has something to do: scrub, toggle, click, step, compare.

03One canvas per plate

Nibbles move a camera across one shared map. You build a spatial picture, not a slideshow.

04Code is evidence, on demand

Click any node, edge or moment to open the validated lines behind it.

05Small or nothing

≤ 7 nibbles, ≤ 40 words, ≤ 12 nodes. Bigger means chapters.

06No knobs

Agents describe what things are. nibble owns every pixel, so the same idea always looks the same.

03 · Visual vocabulary

Seven kinds, each with built-in interactions

The agent writes structure as JSON, and nibble draws it and wires up the controls. P0 kinds ship in the MVP.

map · P0

Services, modules and how they connect.

Click a node for code · highlight a path
sequence · P0

Messages between actors, in order.

Step message by message · branch
timeline · P0

Events from several actors on one clock.

Scrub time · toggle the fix and compare
compare · P0

Before vs after: code, a map or a metric.

Drag the slider · flip
state · P1

A state machine and where you are in it.

Fire events · spot unreachable states
data · P1

The shape of data as it moves through code.

Expand fields · follow one value
chart · P1

Latency, counts, sizes.

Hover values · drag a what-if parameter

06 · Agent side

Strict in, structured out

The CLI enforces the opinions with fix-it messages. The blocked nibble serve exits with the review.

$ nibble add $P --caption "…" --ref "src/cache/prices.ts:43-45 @cache"
✗ rejected: nibble has no visual. Add --visual (map|sequence|timeline|compare).
$ nibble add $P --caption "… 61 words …" --visual stampede.json --ref "…"
✗ rejected: caption is 61 words (max 40). Move detail into the visual or split the nibble.
$ nibble add $P --caption "Every cached price expires on the hour…" \
    --visual stampede.json --ref "src/cache/prices.ts:43-45 @cache"
✓ nibble 2 added (timeline, 3 nodes, 1 control)
$ nibble serve $P      # blocked until you answer

verdict: changes   (exit 2)
