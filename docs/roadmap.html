Roadmap

Stages, not promises — dates are intentionally absent. Scope and decisions live in the PRD; what's listed here follows its decision log. (A plate is the interactive walkthrough nibble builds for a change; a nibble is one step of it.)

done · 2026-11

Design

The PRD, the design mockups with a live reader demo, and every initial open question settled — among them: the CLI is written in Go, v1 gets the Tauri pill, agents describe layout by meaning rather than pixels, and plates live in ~/.nibble.

in progress · v0.1

The MVP: PR review, worktree review, explain

The full loop working end to end in a browser tab, dogfooded on real PRs.

Protocol v1 — the plate file format, fully specified and backed by a tested Go package
Go CLI — the commands an agent uses to build and serve a plate, with validation errors that say how to fix the mistake
Diff refs — point a plate at a diff (your working tree, or any two commits) and it pulls the real code from git
Reader — the page where you read a plate: one canvas the view glides across, the code alongside with live trust badges, comments and a verdict that wakes the agent, new nibbles streaming in while you read
Claude Code skill — teaches the agent when a plate is worth building, with worked examples
Visual kinds — the four visual types: map, sequence, timeline and side-by-side compare, rendered as interactive SVG
Detail dial — every plate readable at two levels: a quick overview, or the full standard view
Blast radius — a map of the PR in three rings: files that changed, files that depend on them, everything else — marking what you haven't looked at yet
Not-shown ledger — each plate ends with a list of the diff changes the walkthrough never covered, so nothing slips by unreviewed
v0.2

Depth and breadth

You can ask for more without leaving the plate, and bigger reviews get structure.

Deep layer + visuals on demand — select anything and ask the agent for more; the answer appears right there as a new visual
Chapter flow — big PRs split into chapters you approve before the walkthrough starts
Voice walk — the plate reads itself aloud, highlighting what it's talking about as it goes
state · data · chart — three more visual types: state machines, data structures and charts
What-if toggles — flip a switch to see the same picture under a different scenario, precomputed by the agent
More agents — Codex and Cursor learn to build plates too, via nibble setup
nibble lint & export — check a plate's visuals without opening it, and save a plate into a repo to share
v1

The pill, and polish

Calm by default, installable in one line, documented.

Tauri pill — a small menu-bar app whose floating pill tells you a plate is waiting (decided 2026-11-01)
Auto-open — plates you asked for open themselves; ones the agent volunteers wait quietly in the pill
Install — one-line install script and a Homebrew tap, with signed builds
User guide — live on this site, tracking the design; final with v1
later

Where the code already lives

Editor panel — read plates inside VS Code or Cursor instead of a browser tab
Continuous what-ifs — what-if sliders with live values, only if real use shows they're worth the complexity
Export storyboard — turn a plate into images and text you can paste into a PR description
Token counts — each nibble and the plate as a whole show how many tokens they took to build, and what that cost
Faster generation — building a plate costs more agent time than it should; measure where the tokens go and cut the waste

Explicitly not planned: themes and layout knobs for agents, hosting plates on a server, telemetry before there's something worth measuring.
