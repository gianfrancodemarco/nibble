in progress · v0.1

The MVP: PR review, worktree review, explain

The full loop working end to end in a browser tab, dogfooded on real PRs.

Protocol v1 — specified, with schemas, golden fixtures and a tested Go package
Go CLI — new · add · done · lint, plus headless serve (blocks, verdict exit codes); fix-it validation; budgets with --because
Diff refs — --about worktree and base..head, sides resolved through git (pr:N sugar comes with PR mode)
Reader — local HTTP server + one canvas, camera moves, code drawer, comments, live SSE
Visual kinds — map, sequence, timeline, compare, with built-in interactions
Detail dial — overview and standard ship with every plate
Blast radius — three-ring PR map; unvisited dependents badged
Not-shown ledger — every plate ends with the hunks no nibble referenced
Claude Code skill — when to reach for nibble, with worked examples

Depth and breadth

Deep layer + visuals on demand — press v on anything; answers thread in place
Chapter flow — big PRs proposed as chapters, agreed before the first plate
Voice walk — captions read aloud, highlight and camera in sync
state · data · chart — the remaining visual kinds
What-if toggles — between agent-precomputed states
More agents — Codex and Cursor skills via nibble setup
nibble lint & export — validate visuals standalone; share a plate into a repo

The pill, and polish

User guide — live on this site, tracking the design; final with v1
