Visuals

An agent describes structure and meaning — nodes, steps, lanes, sides — and the reader draws the picture and wires the controls. Four kinds ship with v0.1; state · data · chart follow in v0.2. Every element an agent names is an anchor: it can carry code, and your comments can pin to it.

map

Services and modules

Tiers become columns, groups sit together, the focus node draws the eye. Click a node — it and its edges highlight, the rest dims; its </> chip opens the code behind it.

sequence

Messages between actors

Lifelines and arrows, revealed one step at a time (space, or click a step). Calls, returns and async fire-and-forgets read differently; alt branches say where it could have gone.

timeline

Events on one clock

Lanes share a single axis; heavier events draw bigger. Scrub time — what hasn't happened yet fades to pending — and toggle precomputed what-if states, like jitter off / on.

compare

Before vs after

Two labelled sides — code (with its trust badge), a nested map, or metrics aligned to read across — and a flip that shifts attention between them.

How this demo works

This is the same app.js the Go binary embeds, pointed at snapshots instead of a live server: the demo plate was authored with the real CLI against a small git repo (docs/demo/), served once with nibble serve, and the JSON it computed — trust badges included — saved as static files. One file was edited after the plate was built, so you can see a shifted badge doing its job on the postgres pool node. Reviews you send here stay in the tab; reload to reset. Regenerate it all with docs/demo/make.sh.
