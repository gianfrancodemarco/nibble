Getting started

Everything you do with nibble, from asking to answering. The short version: your agent runs nibble; you just read, poke and reply.

⚠ nibble is pre-release — v0.1 is in progress. This guide describes the designed behaviour and is kept current as pieces ship; anything not yet real is marked. There is no installer yet; follow the roadmap.

Install ships with v0.1

One install, then your agent does the rest:

$ curl -fsSL https://nibble.dev/install | sh    # or: brew install gianfrancodemarco/tap/nibble
$ nibble setup                                   # installs the skill into Claude Code / Codex / Cursor

setup teaches each agent it finds when to reach for nibble and how to write good plates. After that you never type nibble commands yourself.

What you say

You just talk to your agent:

"review PR #1247"

The #1 use case. Big PRs are proposed as chapters first; you agree before the first plate.

"walk me through one checkout request, end to end"

System parts, request flows — a map and a sequence, the code at every stop.

"walk me through what you just changed"

The uncommitted diff as a map coloured by churn, one compare per claim.
