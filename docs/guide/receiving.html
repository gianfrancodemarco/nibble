A plate arrives

A plate is one explanation: up to ~7 nibbles, each one claim with one visual and the code behind it.

How a plate reaches you follows one rule: the human holds the pen.

You asked for it

It opens itself. You were waiting for it, so there is no extra click.

The agent volunteered it

It waits in the pill (menu-bar icon, v1) until you open it. It never steals focus. v0.1: browser tab

It's still being written

You can open it anyway. Nibbles stream in live while the agent works.

In v0.1 the plate opens in a browser tab. The agent’s nibble serve prints one reader: http://127.0.0.1:… line, and that link is the plate. It is local to your machine and stays alive for as long as the agent waits.

The agent can never advance or close a plate. The command it ran is blocked until you answer. Your reply is what wakes it.
